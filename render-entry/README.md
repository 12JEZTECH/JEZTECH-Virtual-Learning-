# Render entry address

This is a static entry service. It opens the existing JEZTECH Site at https://jeztech-learning.jezreelch.chatgpt.site/login and retains its sign-in, database, payments and media access rules. It is not an independent copy of the application. No credentials or learner records are served here.

Render settings: static site; branch main; build command `test -f render-entry/index.html`; publish directory `render-entry`. The optional `/clips/` entry opens the authenticated Site clip library.
